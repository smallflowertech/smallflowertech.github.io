# KIRO WATCH — Small Flower Technology Store

Static official brand website built with HTML, CSS and vanilla JavaScript. Designed for GitHub Pages.

## Deploy to GitHub Pages
1. Create a new GitHub repository.
2. Upload the contents of this folder to the repository root.
3. In **Settings → Pages**, choose **Deploy from a branch**, select `main` and `/ (root)`.
4. Save and wait for GitHub Pages to publish the site.

## Custom domain
Edit `CNAME` and put your final domain on one line. Then configure the domain DNS according to GitHub Pages instructions.

## Before publishing
- Replace `YOUR-DOMAIN.com` in `sitemap.xml` and `robots.txt` with the final domain.
- Confirm the Shopee URL in `stores.html` and `index.html`.
- WhatsApp is configured from the supplied number as `https://wa.me/6281364434624`.
